# TeachTailor

生徒カルテと学習ログをもとに、一人ひとりに合わせた授業プリント生成用プロンプトを作成するWebアプリです。

Google Apps Script（GAS）とGoogle Sheetsで動作し、Gemini / Claude / ChatGPTなどの生成AIと組み合わせて使用します。

## Background

個別指導では、生徒ごとに「前回どこでつまずいたか」「何がまだ定着していないか」を把握し、次回の授業へ反映する必要があります。

一方で、講師が毎回それらを記憶・整理しながら教材を準備することは負担になります。

そこで、授業で得られた情報を学習ログとして蓄積し、次回の教材作成へ再利用できる仕組みとしてTeachTailorを開発しました。

## Features

- **生徒カルテ**
  - 学習度合、目標、学習環境、性格、指導方針、前回メモを管理

- **学習ログ**
  - 文法事項や単語を「未定着 / 定着」で管理
  - 未定着項目を次回のプリント生成へ反映

- **プロンプト生成**
  - 生徒カルテ・指導方針・過去の学習ログを組み合わせて生成AI向けのプロンプトを作成
  - 授業プリント / 単語テストに対応

- **プレビュー・印刷**
  - 生成AIが出力したHTMLをアプリ上でプレビュー・印刷

- **授業後の記録**
  - プリントから学習項目を取得し、できなかった項目だけを次回の学習ログへ登録

## Flow

```text
生徒カルテ + 学習ログ
        ↓
   プロンプト生成
        ↓
      生成AI
        ↓
    授業プリント
        ↓
       授業
        ↓
   未定着項目を記録
        ↓
   次回の教材へ反映
```

## Tech Stack

- Google Apps Script
- Google Sheets
- HTML / CSS / JavaScript
- Tailwind CSS

## Development

現場で感じた課題の整理、必要な機能・操作フローの設計、実際の授業での運用と改善を行いました。

コードの実装にはClaude / ChatGPTなどの生成AIを活用しています。実際に使用しながら問題点を洗い出し、仕様を修正して改善を重ねています。

## Setup

1. Google Sheetsを作成
2. 「拡張機能 → Apps Script」を開く
3. `Code.gs` と `index.html` を登録
4. Webアプリとしてデプロイ

必要なシートは初回利用時に自動生成されます。
